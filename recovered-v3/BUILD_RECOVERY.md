# Build de recuperación Ministerium 3.0

Este archivo marca la base de compilación del flujo recuperado.

El workflow `.github/workflows/recovered-v3-build.yml` debe compilar este directorio directamente y producir `app-debug.apk` como artefacto.

Criterio P0: Misa + Laudes/Vísperas debe presentarse como una celebración continua que integra Liturgia de las Horas, Misal y Leccionario en una sola pantalla.

# Etiquetas recomendadas

Crear estas etiquetas en GitHub cuando el conector permita administrar el repositorio:

## Tipo
- `type:bug`
- `type:opinion`
- `type:rating`
- `type:suggestion`
- `type:content`

## Módulo
- `module:bible`
- `module:liturgy`
- `module:missal`
- `module:lectionary`
- `module:canon`
- `module:study`
- `module:plans`
- `module:updates`

## Canal / prioridad
- `channel:stable`
- `channel:testing`
- `priority:p0`
- `priority:p1`
- `priority:p2`

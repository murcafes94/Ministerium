# Ministerium 1.7.1

## Corrección de inicio

- Se corrigió el cierre inmediato observado en Android 16 con el mensaje
  `getResources() or getAssets() has already been called`.
- La configuración claro/oscuro se aplica ahora al contexto de cada pantalla
  antes de que Android cree la actividad.
- Se conservan las opciones **Seguir el dispositivo**, **Claro** y **Oscuro**,
  incluidas las pantallas y lectores de la Liturgia de las Horas.

Esta versión mantiene todas las funciones incorporadas en Ministerium 1.7.0.

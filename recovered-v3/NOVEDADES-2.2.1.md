# Ministerium 2.2.1

## Diccionarios sin conexión

- Nuevo selector con cuatro fuentes: **Diccionario bíblico**, **Diccionario
  bíblico abreviado - San Pablo**, **Diccionario de Teología EUNSA 2006** y
  **Diccionario de la lengua española, 15.ª edición**.
- Búsqueda alfabética independiente para cada fuente.
- El diccionario general contiene 85.811 voces y el teológico 94 artículos
  principales.

## Diccionario bíblico convertido a texto

- Se extrajo el texto real de las 1.012 páginas del PDF aportado.
- Se reconstruyó el orden de lectura y se generaron 2.843 entradas buscables.
- Al abrir una voz se muestra únicamente su definición dentro de un recuadro;
  no se presenta la página del PDF, sus columnas ni una fotografía.
- El recuadro conserva el tamaño de letra ajustable, el modo claro/oscuro y el
  funcionamiento completo sin conexión.
- El segundo PDF bíblico, de 442 páginas, se convirtió en 881 voces adicionales
  desde «Aarón» hasta «Zorra y chacal», también como texto en recuadros.
